How to Add This Calculator to Your Website

Copy and paste the following HTML code into your website where you want the calculator to appear:

<div style="position: relative; padding-bottom: 120%; height: 0; overflow: hidden; max-width: 100%; border: 1px solid #ddd; border-radius: 8px;">
  <iframe 
    src="https://your-app-domain.com/embed" 
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: 0;"
    allow="payment"
    allowfullscreen>
  </iframe>
</div>

Notes:

  • Replace https://your-app-domain.com/embed with the actual URL where this calculator is hosted.
  • The padding-bottom: 120% sets the aspect ratio of the iframe. You can adjust this value to make the calculator taller or shorter.
  • The allow="payment" attribute is necessary for the Stripe payment functionality to work.
  • For responsive design, you might want to use media queries to adjust the aspect ratio on different screen sizes.

Advanced Integration

For developers who need more control, you can also use JavaScript to communicate with the iframe:

// Listen for messages from the calculator
window.addEventListener('message', function(event) {
  // Verify the origin for security
  if (event.origin !== 'https://your-app-domain.com') return;
  
  // Handle different message types
  if (event.data.type === 'calculatorComplete') {
    console.log('Calculator data:', event.data.calculationData);
    // Do something with the data
  }
});
