Integration Options

Basic Embed Code

Copy and paste this code into your website:

<iframe 
  src="https://your-app-domain.com/embed" 
  width="100%" 
  height="700" 
  style="border: 1px solid #ddd; border-radius: 8px;" 
  allow="payment" 
  allowfullscreen>
</iframe>

Responsive Embed Code

This approach maintains aspect ratio on all screen sizes:

<div style="position: relative; padding-bottom: 120%; height: 0; overflow: hidden; max-width: 100%; border: 1px solid #ddd; border-radius: 8px;">
  <iframe 
    src="https://your-app-domain.com/embed" 
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: 0;"
    allow="payment"
    allowfullscreen>
  </iframe>
</div>

<style>
  /* Responsive adjustments */
  @media (min-width: 768px) {
    div[style*="padding-bottom: 120%"] {
      padding-bottom: 80% !important; /* Shorter ratio on desktop */
    }
  }
</style>

Advanced Integration with JavaScript Communication

This approach allows two-way communication with the calculator:

<div id="calculator-container" style="position: relative; height: 700px; max-width: 100%; border: 1px solid #ddd; border-radius: 8px;">
  <iframe 
    id="calculator-iframe"
    src="https://your-app-domain.com/embed" 
    style="width: 100%; height: 100%; border: 0;"
    allow="payment"
    allowfullscreen>
  </iframe>
</div>

<script>
  // Listen for messages from the calculator
  window.addEventListener('message', function(event) {
    // Verify the origin for security
    if (event.origin !== 'https://your-app-domain.com') return;
    
    // Handle different message types
    if (event.data.type === 'calculator:loaded') {
      console.log('Calculator has loaded');
    }
    
    if (event.data.type === 'calculator:resize') {
      // Optionally adjust iframe height based on content
      document.getElementById('calculator-container').style.height = event.data.height + 'px';
    }
    
    if (event.data.type === 'calculatorComplete') {
      console.log('Calculator data:', event.data.calculationData);
      // Do something with the completed data
    }
  });
  
  // Example of sending message to calculator
  function sendMessageToCalculator(message) {
    const iframe = document.getElementById('calculator-iframe');
    iframe.contentWindow.postMessage(message, 'https://your-app-domain.com');
  }
  
  // Example usage:
  // sendMessageToCalculator({ type: 'navigate', step: 2 });
</script>

<style>
  /* Responsive adjustments */
  @media (max-width: 767px) {
    #calculator-container {
      height: 800px !important; /* Taller on mobile */
    }
  }
</style>

Implementation Notes

  • Replace https://your-app-domain.com/embed with the actual URL where your calculator is hosted.
  • The allow="payment" attribute is necessary for the Stripe payment functionality to work.
  • For best mobile experience, ensure your website's viewport meta tag is properly set.
  • Test the embedding on different devices to ensure it displays correctly.
